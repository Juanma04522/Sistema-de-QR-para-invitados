# QR Event Manager - Sistema de Gestión de Invitados 🎫

Solución automatizada para la gestión y registro de invitados mediante códigos QR, optimizando el flujo de entrada en eventos profesionales.

## 🛠️ Stack Tecnológico
* **Backend:** .NET / C#
* **Base de Datos:** SQLite / SQL Server
* **Librerías:** Generación de códigos QR dinámica.

## ✨ Características Principales
* **Generación Automática:** Creación de QR únicos por invitado.
* **Registro en Tiempo Real:** Validación de asistencia mediante escaneo.
* **Base de Datos Ligera:** Implementación eficiente para consultas rápidas de invitados.
